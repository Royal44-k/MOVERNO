# MAVERO / 墨维洛 分阶段实施计划

## 1. 已锁定的品牌基线

- 品牌名：**MAVERO / 墨维洛**，英文主标、中文副标；正式发布前完成第 25、35 类商标、域名、社媒账号及公开近似检索。
- 品牌使命：**让黑夜不必黯然，让差异不必喧哗。**
- 长期品牌信念：**Different But Excellent.**
- 产品传播语：**暗中移动，保持柔软 / MOVE DARK. STAY SOFT.**
- 四项价值：柔性防护、真实身体、耐久不规则、安静反叛。
- 视觉比例：75% 静默幕隙、15% 结构科技感、10% 夜间场景质感。
- 禁止复刻十字、皇冠、猿头、鲨鱼、马蹄字环、哥特字标、现有奢侈品牌图案及标志性鞋型。

## 2. 按确认门逐项实施

1. **名称与品牌内核**
   - 检索 `MAVERO`、`墨维洛`、近似拼写及近似读音。
   - 若发现第 25/35 类在先近似服饰品牌，立即暂停 Logo 定稿并返回命名阶段；非服饰同名仅记录风险。
   - 定稿品牌故事、使命、信念句、产品传播语和中英文语气规范。

2. **Logo 首轮**
   - 仅生成 3 套黑白方案，不加入服装、海报或场景效果图。
   - 三套均采用工程化衬线字标，但分别探索：锐利切口、分节连接、柔化机械结构。
   - 每套包含 `MAVERO` 主字标、`墨维洛` 副标、幕隙门徽及横向/纵向/独立徽记组合。
   - 用户选择一套后只在该方向内修订，不自动混合三套方案。

3. **标志性徽记与纹样**
   - 将 `Veil Gate` 升级为可独立识别的“幕隙门徽”：两条错位纵弧围成窄光缝，并在负空间中隐含 `M`。
   - 徽记不得呈十字、皇冠、盾牌、武器或游戏阵营标；机甲感只来自结构节点与分节秩序。
   - 选定徽记后，再开发 `Motion Contour` 连续纹样、五金压印、刺绣、织唛和鞋面微孔版本。

4. **逐款产品开发**
   - 短袖：先比较 3 个轮廓方向，选定后再处理结构、材料、配色与三视图。
   - 裤装：在统一外观下开发 `STRAIGHT`、`CURVE` 双纸样，再制作技术包。
   - 鞋履：先锁定成熟大底和宽前掌鞋楦，再设计基础鞋面及可拆护罩。
   - 每款单独确认后才进入下一款，不一次生成整套成衣。

5. **后续资产与商业化**
   - 产品全部确认后，依次制作模特试穿、发布海报、小红书/抖音内容、品牌手册和 Canva 可编辑物料。
   - 网站最后实施：首页、Drop、商品详情、Lookbook、Fit Lab、品牌页和预售确认；首版不接支付或真实库存。
   - 生产按材料小样、三家 RFQ、样衣、试穿、检测、封样、小批量和 14 天预售补单推进。

## 3. 交付接口与文件规范

- Logo 最终输出：可编辑矢量源文件、SVG、PDF、透明 PNG、纯黑/纯白/反白版本及最小尺寸规则。
- 品牌组合层级：`MAVERO` 为全球主标，`墨维洛` 用于中国市场副标、标签和品牌叙事。
- 商品数据沿用：`slug`、中英名称、价格、材料、颜色、`fitBlock`、尺码、POM、图片、预售状态、交期、洗护与溯源。
- `fitBlock` 仅允许 `UNIVERSAL`、`STRAIGHT`、`CURVE`。

## 4. 验收与测试

- 名称：完成中国商标网、公开网络、主要域名和社媒账号初筛，并保留查询日期与截图。
- Logo：在 16px、8mm、织唛、刺绣和单色压印条件下仍可识别；反向图片检索无明显近似。
- 徽记：遮住字标后仍能辨识，缩小时负空间不闭合，与十字、皇冠和现有品牌符号保持明显距离。
- 品牌语言：`Different But Excellent.` 仅作长期信念；产品页面优先使用功能证据，不以空泛优越感替代说明。
- 产品：正侧背结构一致，技术包无 TBD，功能和环保宣传均由检测、材料文件或试穿数据支持。
- 每个阶段必须得到用户确认，未确认资产不得进入下一阶段或用于公开发布。
