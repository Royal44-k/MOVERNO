# 亚裔青年潮流品牌「夜行护层」0→1 计划

## 1. 品牌定位与研究基线

- 面向中国大陆首发、后续辐射亚洲市场的 18–30 岁年轻人；中性视觉，裤装采用直身/曲线双纸样，不以男女标尺码。
- 定位为中端独立设计师品牌：短袖 ¥499、长裤 ¥899、鞋 ¥1,299；核心承诺为“暗色第二层皮肤”，默认传播语为“暗中移动，保持柔软 / MOVE DARK. STAY SOFT.”
- 研究以 [Size Korea](https://sizekorea.kr/about/intro) 人体数据、东京与[首尔 SS26 街拍](https://www.vogue.co.jp/gallery/the-best-street-style-from-seoul-fashion-week-spring-2026)、日韩艺人机场/私服造型及中国用户访谈共同校准，不把“亚裔版型”简化为缩小欧美尺码。
- 参考矩阵只提炼方法：从 [Rick Owens](https://www.rickowens.eu/en-us) 学纵向比例与暗色建筑感，从 [Acne Studios](https://www.acnestudios.com/emea/gi/en/woman/ss26/) 学基础款错位与材质反差，从 [Chrome Hearts 官方站](https://www.chromehearts.com/) 学五金仪式感与稀缺陈列，从 [ADERERROR](https://www.adererror.com/en/curated/2026ss)、[HOMME PLISSÉ](https://uk.isseymiyake.com/blogs/news/17980)、[and wander](https://www.andwander.com/look-2026ss.html) 和 [ASICS SportStyle](https://www.asics.com/jp/ja-jp/mk/sportstyle) 学隐藏结构、可变穿法与运动科技。
- 禁止复刻十字、匕首、马蹄字环、哥特字标、Rick Owens 标志性鞋型、Acne Face 等识别资产；用户提供的 `chromeheartswear.com` 仅作第三方页面观察，不作为官方设计依据或购买建议。
- 结合 2026 小红书服饰研究中“长期持有、轻量负担、状态表达”的信号，以及中端市场价值机会，建立“功能证据＋情绪叙事”而非追逐单季爆款的路线。[小红书报告镜像](https://www.fxbaogao.com/detail/5621429)、[Textile Exchange 2025](https://textileexchange.org/knowledge-center/reports/materials-market-report-2025/)、[State of Fashion 2026](https://www.businessoffashion.com/reports/the-state-of-fashion-industry/)

## 2. 品牌与首发产品系统

- 命名阶段生成 12 个原创中英双语候选，按发音、亚洲语境、域名/社媒账号和中国商标近似风险筛至 3 个，由用户选择最终品牌名。首轮检索第 25 类和第 35 类；配饰扩张前再覆盖第 18、14 类，并通过[中国商标网](https://sbj.cnipa.gov.cn/)复核。
- 建立四项品牌价值：柔性防护、真实身体、耐久不规则、安静反叛。
- 标志系统以原创“幕隙 Veil Gate”为核心：两条错位纵向弧线形成窄负空间；延展纹样“Motion Contour”来自肩—胯—前掌的动态压力/垂坠轨迹。
- 色彩锁定为 Obsidian `#0D0D0F`、Graphite `#25262A`、Bone Ash `#D9D4C8`、Oxidized Nickel `#73777A`、Dried Blood `#5B1F25`；暗血红仅作 5% 以下的隐藏点色。
- 首发 SS27 胶囊包含：
  - `SS27-TS01 VEIL TEE`：260gsm、92% 精梳棉/8% 莱赛尔，酵素柔洗；延长袖、弧形侧缝、隐藏侧袋和可调后摆。黑曜、骨灰两色。
  - `SS27-PT01 ARC TROUSER`：约 190gsm 锦棉弹力斜纹，非含氟防泼整理；弧形裤腿、裆部活动片、浮层口袋、隐藏通风与可调裤脚。黑曜一色，直身/曲线两套纸样，各 S–XL。
  - `SS27-SH01 SHROUD RUNNER`：成熟大底二次开发，不开专属底模；适应东亚较宽前掌的鞋楦，不对称可拆护罩、透气网布、微纤绒面、高回弹鞋垫与耐磨橡胶底。黑曜/氧化镍一色，EU 35–45 预售配码。
- 每款建立工厂可读技术包：正/侧/背技术平面图、局部放大、BOM、POM、车缝与五金说明、尺码级放、容差、色卡、标签包装和质检项目；AI 效果图不能替代技术图或实体样衣。
- 招募至少 12 位东亚试穿者覆盖两种版型与不同身高比例，进行站、坐、蹲、跨步、抬臂及鞋履步行测试；两轮服装样衣、三轮鞋样后才锁大货。

- 先用图像生成技能制作恰好 3 套独立视觉方向，用户选择后再扩展，避免边设计边混合风格。
- 完整交付包包括：

  - 每款 A3/300dpi 高保真正侧背三视图、细节图和统一比例技术图。
  - 两位代表不同版型的东亚模特全身试穿正侧背图、动态城市造型、白底商品图和材质微距。
  - 发布主视觉：4:5 海报、9:16 抖音封面、16:9 网站 Hero、1:1 商业头像；先生成无文字摄影，再在 Canva MCP 中排入准确文案，形成可编辑版本。
  - 小红书 9 页图文模板：品牌宣言、版型证据、面料拆解、三件套穿搭、试穿对比、开发幕后、价格解释、预售规则、行动页。
  - 抖音 6 条短视频脚本与封面：3 秒廓形钩子、结构变形、双版型对比、鞋面拆解、夜行造型、首发倒计时；附镜头表、旁白、字幕和 CTA。
- 网站先生成 3 个独立 UI 视觉候选，选择后构建响应式可运行原型；页面包括首页、Drop 列表、商品详情、Lookbook、Fit Lab/品牌页及预售确认。
- 核心购买路径必须可交互：浏览 → 选择版型与尺码 → 查看测量方法 → 加入预售/候补 → 确认；支付、真实库存和上线部署不纳入首版。
- 商品数据接口统一为：`slug`、中英名称、价格、材料、颜色、`fitBlock`、尺码、POM 测量、图片、库存/预售状态、交期、洗护和溯源；`fitBlock` 仅使用 `UNIVERSAL`、`STRAIGHT`、`CURVE`。
- 网站采用“幕隙”纵向揭幕作为唯一主动画，支持键盘操作、移动端、减少动态偏好和中英切换，避免堆叠卡片式模板感。

## 4. 商业落地与 28 周节奏

- 采用“小批现货＋14 天预售补单”的 Drop 模式；首批优先短袖和裤装现货，鞋履以订金/候补验证配码后排产，页面明确预计交期和退款规则。
- 以约 ¥38 万为基准预算：研究与知识产权 ¥2.5 万、设计/技术包/打样 ¥9 万、检测 ¥3 万、首批货款 ¥12 万、拍摄与内容 ¥5 万、网站与工具 ¥2 万、种子达人/测试投放 ¥2.5 万、预备金 ¥2 万。
- 生产流程为：材料小样 → 3 家供应商 RFQ → 成本/质量/交期评分 → 样衣 → 试穿修版 → 第三方检测 → 封样 → 小批量生产；供应商不得仅凭效果图报价。
- 28 周里程碑：
  - 第 1–3 周：研究、用户访谈、命名与商标初筛。
  - 第 4–7 周：品牌视觉、产品概念和首轮三视图。
  - 第 8–15 周：技术包、供应商 RFQ、样衣与双版型测试。
  - 第 16–20 周：封样、检测、成本确认、候补名单和内容预热。
  - 第 21–25 周：大货、网站原型、宣传物料和达人寄样。
  - 第 26–28 周：预售测试、2027 年 3–4 月首发、复盘补单。
- 冷启动目标：有效候补名单 ≥1,000、首发内容收藏率 ≥5%、商品页转化率 ≥2%、30 天售罄率 ≥60%、退货率 ≤12%、履约前毛利率 ≥65%。
- 补齐商标、域名/账号、模特肖像授权、摄影版权、供应合同、抽检标准、中文标签、洗护、售后、包装、库存现金流和可持续材料声明证据；生产前按[产品质量法](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_579118cd202a45fba28b7edfd9f6fd72.html)及届时有效的[纺织品服装使用说明标准](https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D7E223D3A7E05397BE0A0AB82A)再次核验。
