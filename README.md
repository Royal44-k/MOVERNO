## 品牌与阶段

面向中国大陆首发、后续扩展亚洲市场的 18–30 岁年轻人。核心为暗色、结构秩序、柔性防护和克制的工业金属细节。视觉基线由用户选定：75% 静默幕隙、15% 结构科技、10% 夜间环境质感。后续实际款式选择和例外记录优先于早期泛化规则。

`MAVERO` 是历史候选，不是本次新增品牌。其公开同名风险促成了 `MORVENOR → MOVERNO` 的后续筛选；`MOVERNO / 墨维诺` 在项目记录中获准用于内部概念设计，尚无商标核准或实物封样证明。

仓库是**设计工作档案**。款式主图、模特视觉、详情长页和广告均按各轮记录归档，不能因为文件名含 `final`、`selected` 或 `Tech Sheet` 就认定已获用户最终批准、可投入大货或已经实际测试。

## 文件组织

```text
archive/       归纳文档、决策、来源、全量清单、恢复说明
project/       可浏览的文档、脚本、身份资产及代表预览

```

`project/` 的原有相对结构保持不变。Git 中只放可浏览的源文件及部分预览；高分辨率原图、嵌入图像的 SVG、全部视频、历史 ZIP 和其他大文件位于 Release。完整下载恢复后才能离线打开所有 HTML 画廊与制作工程。

历史研究保持原查询日期，本次归档没有重新核验商标、域名、趋势或价格。外部参考图的原权利归其权利人；包含参考图的审款板不能直接当作本品牌商品宣传。详见[来源与权利说明](archive/06-provenance-and-rights.md)。

本次归档依据用户明确上传请求；没有新生成款式、替用户选择设计、部署网站或发布社媒广告。原项目目录保持原状。
