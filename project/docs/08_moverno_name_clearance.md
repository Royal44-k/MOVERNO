# MOVERNO / 墨维诺 名称公开初筛

核验日期：2026-08-27（Asia/Shanghai）  
内部结论：**CONDITIONAL PASS — 可进入非公开 Logo 概念探索**

## 直接结论

公开精确词搜索暂未发现名为 `MOVERNO` 或 `墨维诺` 的服装、鞋履品牌或第 25/35 类明确在先记录。`MOVERNO` 与此前被否决的 `MORVENOR` 相比，不再完整包含成熟品牌 `MORVEN`，整体拼写、音节和视觉节奏具有更清楚的独立性。

但近似检索发现 `MOVER` 与 `MOVERE` 已被真实服饰品牌使用，且海外存在有效的 `MOVER` 第 25 类记录。因此本次只给出“内部视觉探索通过”，不把它表述为低风险或商标核准。中国大陆公开发布、打样织唛、鞋标及商业投放前，仍须由商标代理人对第 25、35 类完成文字、图形、拼音和近似读音检索。

| `MOVERNO` 精确词 | 搜索结果主要指向奥地利搬运服务及波兰培训/企业服务，未见同名服饰品牌 | 同类精确占位风险暂低 |
| `墨维诺` 精确词 | 公开搜索未见服装、鞋履或零售品牌结果 | 中文精确占位风险暂低 |
| `MOVER` | Mover 官方网站经营塑料零添加运动服；美国公开记录显示 `MOVER` 第 25 类有效注册 | 与目标品类重叠，构成中等近似风险 |
| `MOVERE` | `MOVERE` 自称高端 athleisure 品牌，读音接近 “mover” | 增加英语口语环境的近似认读风险 |
| `MODERNO` | 美国公开记录覆盖服装、鞋、腰带，但词形与发音均不等同 `MOVERNO` | 记录为远端近似，不单独触发停止条件 |
| 域名 | 查询时 `moverno.com` 可注册；`moverno.cn` 与 `moverno.com.cn` 不可购买或查询失败 | `.com` 是正向资产；中国域名状态需向注册商复核 |

## 名称结构

- 建议发音：`mo-VER-no`，三音节，重音置于中段。
- `MOVE` 暗合移动与身体状态，但不把功能承诺写成“运动品牌”。
- `-RNO` 使整体与普通英语单词 `MOVER` 拉开视觉距离，并形成更建筑化的尾部节奏。
- 中文继续使用 `墨维诺`：墨＝夜色，维＝结构与保护，诺＝长期品质、履约和功能承诺。

## 使用边界

- 当前允许：内部 Logo 概念、字形可读性、徽记负空间和缩放测试。
- 当前不允许：公开账号占位宣传、正式织唛/鞋标下单、大货包装、付费投放或“已注册”表述。
- 下一法律门：在中国商标网与代理人检索中覆盖 `MOVERNO`、`墨维诺`、`MOVER`、`MOVERE`、`MOVERNO` 的音译近似及图形门徽；重点核验第 25、35 类。
