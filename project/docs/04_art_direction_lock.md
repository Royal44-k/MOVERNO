# 方向 1.1 锁定：Silent Aperture / 静默幕隙

确认日期：2026-08-26

用户选择方向 1，并指定少量融入方向 2 的科技机甲感与方向 3 的场景细节。以下规则从本阶段起约束 Logo、图案、产品、影像与网站；每一阶段单独确认，不提前生成整套成衣。

## 1. 融合比例

- **75% 静默幕隙**：纵向比例、窄光缝、黑曜建筑面、克制留白、安静姿态。
- **15% 动态膜层**：结构数据感、微孔/网布、分节五金、可拆连接、肩—胯—前掌运动轨迹。
- **10% 柔性氧化**：酵素洗表面、磨砂微纤、氧化镍、雨后地面、维护通道或洗衣房的生活痕迹。

## 2. “机甲感”的正确转译

机甲感不是盔甲外形，而是“可读的结构秩序”：

- 用弧形裁片、嵌线、活动片和通风区表现身体关节。
- 五金采用薄型、低凸、可替换的氧化镍部件；避免尖刺和武器联想。
- 鞋罩、裤袋浮层和后摆调节具有真实功能，拆除后主体仍完整。
- 技术线条每个视面最多 2–3 条，主结构优先，拒绝无功能装饰线堆叠。
- 不做外骨骼、胸甲、肩甲、战术装甲、赛博发光管或科幻 cosplay。

## 3. 场景细节

首发影像的主场景为“夜间城市维护层”，包括：

- 地铁末班后的维护通道、窄门缝光、湿润反射地面。
- 深夜自助洗衣房、磨损金属座椅、柔和骨灰色荧光。
- 便利店外的背光玻璃、雨后路面、少量氧化表面。

场景服务于材质和身体，不出现拥挤霓虹、末世废墟、武器、车辆追逐或泛赛博朋克符号。

## 4. 视觉常量

- 主色：Obsidian `#0D0D0F`、Graphite `#25262A`。
- 辅色：Bone Ash `#D9D4C8`、Oxidized Nickel `#73777A`。
- 隐藏点色：Dried Blood `#5B1F25`，单一画面不超过 5%。
- 主构图：一条纵向窄负空间；只保留一种主动画“纵向揭幕”。
- 主质感：哑光、柔洗、磨砂、低反射；镜面金属只能作为极小细节。
- 摄影：真实东亚成年模特、低表演感、完整身体比例、可核验服装结构。

## 5. 跨模块边界

- Logo 阶段只处理文字标、图形标和组合关系，不同时设计服装。
- 标志性图案阶段只处理 `Veil Gate` 和 `Motion Contour` 的几何系统、缩放与工艺适配。
- 产品阶段按短袖 → 裤装 → 鞋履顺序；每款先轮廓与版型，再结构，再材质和配色，最后技术图。
- 影像与网站只使用已经确认的品牌与产品资产，不反向修改产品结构。
