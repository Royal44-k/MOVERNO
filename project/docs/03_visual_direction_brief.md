# 三套视觉方向生成简报

三套方向必须彼此独立，只共享以下硬约束：

- 面向 18–30 岁亚洲青年，中性、城市、暗色、柔性防护。
- 核心图形为原创 `Veil Gate`：两条错位纵向弧线构成窄负空间。
- 延展 `Motion Contour` 来源于肩—胯—前掌的运动/垂坠轨迹。
- 固定色：Obsidian `#0D0D0F`、Graphite `#25262A`、Bone Ash `#D9D4C8`、Oxidized Nickel `#73777A`、Dried Blood `#5B1F25`；暗血红不超过 5%。
- 不出现十字、匕首、马蹄字环、哥特字标、猿头、鲨鱼、迷彩、星形鞋标、Acne Face、现成品牌 Logo 或可识别鞋型。
- 视觉稿不生成可读文案；准确文字在用户选择后进入 Canva 排版。

## 方向 1：Silent Aperture / 静默幕隙

建筑化、克制、纵向。黑曜和骨灰承担 90% 画面，氧化镍只在五金和细线中出现。产品像从窄光缝中显露，强调长比例、平静站姿和高留白。

## 方向 2：Kinetic Membrane / 动态膜层

技术化、流动、可验证。用轨迹线、半透明覆层、风和步态表现结构；银灰比重更高，突出双版型、通风、弧腿和可拆鞋罩的运动逻辑。

## 方向 3：Tender Oxide / 柔性氧化

触觉化、穿旧感、安静反叛。酵素洗表面、磨砂微纤、氧化镍和微量暗血红形成温度；近距离身体与材质关系强于冷峻科技感。
