## 参考图共同审美密码

1. **黑色主体优先**：黑曜/石墨占 70–90%，骨灰承担结构说明；沙灰只出现于复古科技跑鞋方向。
2. **轮廓先于图案**：偏好可一眼区分的鞋帮高度、鞋底体积和鞋面覆盖逻辑，而不是靠彩色印花制造差异。
3. **一条强识别面**：经典鞋款多用侧标或单块侧片；MOVERNO 将其替换为“结构化 Motion Contour”，不制造新的仿品牌侧标。
4. **粗细对比**：宽鞋带/厚底与低帮/薄鞋面并置；高帮则用纵向鞋舌和分节鞋领拉长比例。
5. **材质同色异质**：哑光皮、微纤绒、网布、帆布、橡胶处于同一色相，仅靠光泽和肌理分层。
6. **科技感来自连接**：笼架、带条、扣件、拉链、护罩必须解决锁定、耐磨、透气或穿脱问题；不增加无功能机甲装饰。

## 品牌资产在鞋身上的五种合法用法

| 级别 | 用法 | 最佳部位 | 面积/工艺上限 |
|---|---|---|---|
| A | 门徽作为真实结构件 | 扣件、拉链头、护罩铰点、后跟稳定片开槽 | 外露 8–16 mm；中缝不得闭合 |
| B | 纹样作为裁片边界 | 滑板耐磨片、跑鞋支撑片、靴筒拼接 | 单侧仅 1–2 个放大单元 |
| C | 纹样作为开孔/提花节奏 | 网布、袜套、鞋领内层 | 同色、低对比，不做满版字母 |
| D | 纹样作为底墙折面 | 厚底侧墙、足弓窗口 | 只保留几何节奏，不复制源图材质效果 |
| E | 字标作为精确信息 | 鞋舌织标、鞋垫、包装 | 概念图留空；后期置入矢量，不由模型生成 |

## 对余下概念图的即时修正

- 每款只选择 **一个主品牌动作**，其余 Logo/纹样降为次要或不出现，避免“贴满品牌资产”。
- 低帮系列强化图 07/11 的黑骨灰秩序，但以方头、绑带、莫卡辛、滑板四种不同结构区分。
- 高帮系列只提取图 03 与图 06 的高度和穿着张力，全面避开圆踝章、超长舌、经典包头和标志性侧片。
- 技术跑鞋与笼架系列提取图 01/05 的叠层和锁定逻辑，限制为一个鞋楦平台下可制造的覆片、织带或护罩。
