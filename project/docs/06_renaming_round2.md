# 第二轮命名筛选（12 → 3）

更新日期：2026-08-27  
目标：延续用户喜欢的“国际设计师姓氏感”，同时满足读音顺、中文有内涵、暗色科技气质与跨服装/鞋履延展。

## 命名规则

- 英文控制在 2–4 个自然音节，避免 `Y/Q/X` 等需要教学的拼写。
- 中文不是机械音译：字义必须能回到品牌使命、真实身体、结构保护和安静反叛。
- 不把 `dark`、`black`、`tech`、`street` 直接写进名称，避免品类化和短期化。
- 公开检索无明显同类品牌、主 `.com` 本次可购，才进入前三。
- 本轮仍是公开初筛，不替代中国第 25、35 类正式商标检索。

## 三个候选的品牌适配

### 1. MORVAIRE / 墨维尔

- 最像成熟设计师品牌姓氏，二拍读音利落，适合字标与鞋舌短标。
- 中文“墨维尔”可解释为“在夜色中维持真实的你”，与使命衔接最自然。
- 风险：英文尾音可能被部分人读作 `vair` 或 `ver`；品牌手册需固定读音 `mor-VAIR`。

### 2. MORVENOR / 墨维诺

- 三拍更稳重，具有建筑、机构与长期品牌感；适合中端设计师路线。
- “诺”把耐久、交付与功能证据变成品牌承诺，不只是情绪词。
- 后续发现的决定性风险：`MORVEN` 是覆盖 T 恤、裤装、鞋履与配饰的成熟男装品牌，并在海外拥有服装及零售服务相关注册；`MORVENOR` 完整包含 `MORVEN`，因此不进入 Logo。

### 3. VARENIEL / 维然曜

- 与前两名区别最大，声音更轻、更未来，适合 15% 的结构科技感。
- “维然曜”可读为“维持真实，在暗处仍有光”，直接连接品牌使命。
- 风险：英文为四音节倾向，首次口述需验证是否被缩读为 `va-NEEL`。

## 选择后的硬门

1. 中国商标网第 25、35 类：英文、中文、连写、分写、近似拼写与近似读音。
2. 小红书、抖音、微博、Instagram、TikTok 精确账号与相近账号。
3. 15 人“看 5 秒—遮住—复述”测试，记录读音、拼写、联想。
4. 用户确认后才生成恰好 3 套纯黑白 Logo；未确认前不做服装、海报或网站。
