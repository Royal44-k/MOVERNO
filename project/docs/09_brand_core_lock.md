# MOVERNO / 墨维诺 品牌内核锁定

确认日期：2026-08-27

## 品牌层级

- 全球主标：`MOVERNO`
- 中国市场副标：`墨维诺`
- 建议英文发音：`mo-VER-no`
- 中文释义：墨＝夜色；维＝结构与保护；诺＝长期品质、履约与功能承诺。

## 品牌语言

- 品牌使命：**让黑夜不必黯然，让差异不必喧哗。**
- 长期信念：**Different But Excellent.**
- 产品传播语：**暗中移动，保持柔软 / MOVE DARK. STAY SOFT.**

## 四项价值

1. 柔性防护：保护来自材料、结构和适应性，不来自盔甲化造型。
2. 真实身体：以试穿数据和双版型回应差异，不以性别尺码替代身体事实。
3. 耐久不规则：让使用痕迹成为质感，同时以耐用和可维护为前提。
4. 安静反叛：拒绝高声量符号堆叠，以比例、负空间和细节表达差异。

## 中英文语气

- 中文：简短、克制、具体；优先说明结构证据、触感和使用状态。
- 英文：短句、主动语态、低修饰；避免把 `Excellent` 写成对他人的优越判断。
- 功能表达：使用“经试穿验证”“材料文件显示”“测试条件下”等可核验措辞。
- 禁用：最适合亚裔、绝对防水、永久耐用、完全可持续、颠覆一切等绝对化表述。

## 当前视觉任务

只探索三套独立纯黑白 Logo 方案：工程化衬线字标、`墨维诺` 中文副标、幕隙门徽及横向/纵向/独立徽记组合。此阶段不进入服装、海报、场景、网站或彩色延展。
