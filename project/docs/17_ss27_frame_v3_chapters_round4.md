# MOVERNO / 墨维诺 SS27 FRAME V3 五款图形章回 Round 4

日期：2026-08-29  
状态：五款正背视觉概念与后领标细节均已完成，等待用户统一审核；未进入侧视图、技术平面、POM、BOM 或打样。

## 本轮目标

本轮专门重做潮流网红款 `FRAME V3` Oversize 的图形系统。漫画风不再画人物、城市或幼稚角色，而是把 MOVERNO 的 `Veil Gate` 与 V2 Relay Veil 本身漫画化；同时通过鎏金、色差、复古运动和极简负形扩展成五种成熟风格。

共同版型视觉目标为：明显落肩、宽阔但受控的箱型衣身、近肘宽袖、前约 72 cm / 后约 74 cm 的 M 码概念衣长、轻微后身余量和浅弧侧缝。数值是概念目标，不替代后续纸样与真人试穿。

## 五款审核图

### 01 — VEIL CHAPTER / 幕隙章回

![01 VEIL CHAPTER](../assets/ss27-frame-v3-chapters-round4/01-veil-chapter.png)

- 衣身：洗水黑曜炭灰。
- 语言：V2 被拆成斜向分格、透视接力隧道、网点和干刷残影。
- 角色：五款中漫画叙事最强；图形主体仍是门徽而非人物。
- 品牌：前胸小门徽 + `MOVERNO`；后领标单独放大。

### 02 — GILDED IMPACT / 鎏金冲格

![02 GILDED IMPACT](../assets/ss27-frame-v3-chapters-round4/02-gilded-impact.png)

- 衣身：梅紫黑 / 黑化茄紫。
- 语言：冲击式断格、V2 旋转和递进残影。
- 鎏金：只作为黑色面板和分格的细边线；面板内部保持暗黑。
- 品牌：左胸小门徽 + `MOVERNO`；后领标单独放大。

### 03 — CHROMA ECHO / 色差残像

![03 CHROMA ECHO](../assets/ss27-frame-v3-chapters-round4/03-chroma-echo.png)

- 衣身：低饱和石油蓝 / 风暴青。
- 语言：青蓝、梅紫和骨灰套色错位，配合断层、透明残影和跨袖延续。
- 品牌：移至前下摆，后背仅保留微型门徽，避免五款全部固定左胸。
- 作用：在不进入高亮霓虹或游戏 UI 的前提下提供社媒视觉抓力。

### 04 — SIGNAL LEAGUE / 信号联盟

![04 SIGNAL LEAGUE](../assets/ss27-frame-v3-chapters-round4/04-signal-league.png)

- 衣身：带灰骨白主体、氧化酒红袖肩、石墨领口与微量风暴蓝线。
- 语言：将 V2 转译为原创赛道、信号门和计时刻度；不使用现成球队、学院徽章或赞助标。
- 品牌：前胸门徽 + `MOVERNO`；后背横向品牌栏仅出现一次。
- 作用：扩展复古运动/嘻哈穿搭场景，同时保留品牌建筑秩序。

### 05 — SILENT NEGATIVE / 静默负片

![05 SILENT NEGATIVE](../assets/ss27-frame-v3-chapters-round4/05-silent-negative.png)

- 衣身：雾蓝灰 / 氧化镍蓝。
- 语言：大面积留白、低对比负形、哑光与微光表面差、稀疏网点消散。
- 品牌：袖口微字标，前胸仅以几乎不可见的同色门徽存在。
- 作用：作为五款中的成熟极简收束款，近看才显露层次。

## 系列差异检查

| 维度 | 01 幕隙章回 | 02 鎏金冲格 | 03 色差残像 | 04 信号联盟 | 05 静默负片 |
|---|---|---|---|---|---|
| 主色 | 黑曜炭灰 | 梅紫黑 | 石油蓝 | 骨白/酒红 | 雾蓝灰 |
| 图形密度 | 高 | 中高 | 中 | 中高 | 低 |
| V2 变化 | 分镜/透视 | 旋转/断裂/鎏边 | 错版/残影 | 赛道/号牌秩序 | 负形/消隐 |
| 社媒第一眼 | 强黑白冲击 | 暗奢光线 | 冷彩动势 | 明暗撞色 | 低调质感 |
| 品牌位置 | 左胸 | 左胸 | 下摆/后颈 | 左胸/后背栏 | 袖口/同色前胸 |

验收结论：五款保持统一 `FRAME V3` 家族比例，但并非换色复制；主色、图形密度、品牌位置与视觉情绪均有明显区分。五款均包含后领品牌标示细节，未使用人物、现成漫画 IP、球队标识或受保护潮牌资产。

## 统一审核方式

请对每款回复 `保留 / 修改 / 淘汰`，并可附一句最重要的修改意见。例如：

`01 保留；02 金边减少 20%；03 保留；04 背图缩小；05 提高门徽对比。`

只有审核通过的设计才进入下一阶段：统一正、侧、背结构重建，图形局部放大，材料/色卡定义以及技术平面准备。

## 方法与边界

- 本轮按 StyTrix 的项目化方法管理：同一版型基线、单款独立生成、明确材质/图形/领标、统一审核门；没有调用 StyTrix 付费生成，也未消耗其点数。
- 五款均由 ImageGen 独立生成，避免同批生成造成风格串扰。
- 当前图像用于方向确认。图中文字、细线和跨接缝关系需在进入技术平面阶段时用确定性矢量重建，不能直接作为印花生产文件。
