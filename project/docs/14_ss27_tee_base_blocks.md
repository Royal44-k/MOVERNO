## 当前版型差异

- `FRAME V2 / INFLUENCER OVERSIZE`：深落肩、近肘宽袖、宽而缩短的箱型衣身，轻微前短后长；修正旧版纵向拖长感。
- `TRACE V2 / FITTED CROP`：自然至微落肩、中性男装式轻收腰、上臀短衣长、前后齐平；不做沙漏、外摆或露脐。
- `RHYTHM V / HIP-HOP MICRO-V`：浅微 V 领、黑色宽罗纹、落肩宽袖、肩部黑对黑拼接线与短侧开衩。
- `NOIR POLO / MODERN PIQUE`：黑色珠地、两粒扣短门襟、罗纹领袖口、轻度收腰、侧开衩与克制后长下摆；无马球标志或撞色。
- `NOCTURNE SHIRT / BLACK BUSINESS`：男士 tailored fit、半开角领、无胸袋法式门襟、长袖单扣袖口、背过肩与收省、可扎入西裤的商务弧形衣尾。
