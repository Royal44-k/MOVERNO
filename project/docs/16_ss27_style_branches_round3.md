# MOVERNO / 墨维诺 SS27 短袖风格支线 Round 3

日期：2026-08-28  
状态：五条支线的正背高保真概念与领标细节已完成，进入用户审核；尚未进入三视图、POM、BOM 或工厂技术包。

## 本轮要解决的问题

上一轮 V2 与结构科技语言辨识度明确，但连续使用会造成“黑色底 + 机械铺装”的单一印象。本轮把 V2 从全系列强制母题调整为可选品牌资产，建立五条彼此独立、但仍符合“柔性防护、真实身体、耐久不规则、安静反叛”的视觉支线：柔性、漫画叙事、成熟针织、极简材质和冷静流体。

共同规则：

- 每款必须有黑底骨灰色的内后领品牌领标，使用幕隙门徽与 `MOVERNO`。
- 主色不再等同于纯黑；深色用于压住情绪，冷蓝、玉灰、梅紫、骨白和暗酒红承担层次。
- 标志纹样可以旋转、断裂、残影化或隐入组织，但不再要求每款出现 V2。
- 新图形必须原创，不使用现有动漫角色、艺术家风格、奢侈品牌图案或识别性鞋/服装资产。
- 本轮图像是视觉方向与款式概念，不替代工厂技术图或实体样衣。

## 研究信号如何进入设计

- TikTok 的 2026 趋势与服饰创意资料强调真实过程、试穿、单品多种穿法、品牌理念和购买理由，因此每款都保留可被拆成“廓形—材质—图形—领标”内容模块的结构，而不是只做一张难以解释的海报。
- 小红书 2026 春夏观察中的 `Softfit`、`Airy Layering` 与 `Offduty` 信号分别进入柔隙的半透叠层、静流的轻垂与 FRAME 的社媒 oversize 比例。
- Pinterest 2026 Palette 的 Cool Blue `#D7EFFF`、Jade `#AEB8A0` 与 Plum Noir `#351E28` 被转译为低饱和服装色，而不是直接复制成高亮趋势色块。
- Uniqlo U 2026 SS 的 tinted white、washed blue、轻透材质和基础款再解释，支持 `QUIET UNIT` 以材质、反向接缝和非对称色块取代大图案。
- COS、ISSEY MIYAKE 与 2026 东京/首尔街拍提供结构与流动并置、景观取色、流体形态和性别包容比例的参考；仅提炼方法，不复制单品。

## 五条支线

### 01 — SOFT RIFT / 柔隙

文件：`assets/ss27-tee-style-branches-round3/01-soft-rift-curve-crop.png`

- 新版型 `CURVE CROP`：高胯短身、柔化落肩、近肘开袖、非对称弧形下摆与单侧半透明底层；不裸腰、不做紧身刻板女装。
- 色彩：烟紫灰、墨海军蓝、骨灰、冰冷蓝。
- 图形：原创夜生 X-ray 植物、液态模糊与半透明残影，从前下侧断开后在后肩重现。
- 品牌：左胸小型门徽 + `MOVERNO`；领标单独放大。

### 02 — INK SEQUENCE / 墨格连载

文件：`assets/ss27-tee-style-branches-round3/02-ink-sequence-frame.png`

- 版型 `FRAME`：宽肩、近肘袖、箱型但控制衣长，保留社媒 oversize 的显比例能力。
- 色彩：褪色青绿、炭灰、纸骨白，暗血红只做错版点色。
- 图形：原创无脸夜行者与城市分镜；网点、速度残影、撕页边和套色偏移跨越前身、袖子与后肩，不形成完整广告矩形。
- 原创边界：无现有漫画角色、无特定漫画家风格、无武器。

### 03 — AFTER HOURS / 夜后

文件：`assets/ss27-tee-style-branches-round3/03-after-hours-open-collar-knit.png`

- 新版型 `OPEN-COLLAR KNIT`：无纽扣开领、紧凑上胯衣长、正肩、窄袖口与侧开衩。
- 色彩：深橄榄炭、梅紫酒红、石墨与羊皮骨白。
- 质感：微人字针织、低对比纵纹、光线下才出现的抽象门徽暗提花；左胸为同色压纹。
- 定位：成熟夜间社交与设计师日常，不采用经典 Polo 品牌的图标或配色公式。

### 04 — QUIET UNIT / 静默单元

文件：`assets/ss27-tee-style-branches-round3/04-quiet-unit-trace.png`

- 版型 `TRACE COMPACT`：控制肩线、短而不露腰、纵向收束、微侧阶下摆。
- 色彩：带灰骨白、洗水钢蓝、石灰与黑曜微标。
- 结构：斜向反缝、单袖/侧片不对称配色、两次中断的 2 mm 偏移线、同色压纹门徽；无大图。
- 定位：靠比例、面料与缝线建立辨识度的冷静日常款。

### 05 — STILL CURRENT / 静流

文件：`assets/ss27-tee-style-branches-round3/05-still-current-drape-wing.png`

- 新版型 `DRAPE WING`：软延肩与轻蝙蝠袖、近肘袖长、收束侧身、弧形开衩、后长 20 mm 的视觉目标。
- 色彩：雾蓝、玉灰绿、雨云紫、氧化银。
- 图形：原创水波干涉、雨窗折射、稀疏等高涟漪和矿物颗粒，由前下侧消失后在背部与袖侧重新出现。
- 品牌：门徽移到前下摆，避免所有款都固定左胸。

## 系列节奏检查

| 维度 | 01 柔隙 | 02 墨格连载 | 03 夜后 | 04 静默单元 | 05 静流 |
|---|---|---|---|---|---|
| 廓形 | 曲线短身 | 网红 oversize | 紧凑开领针织 | 修身短身 | 流动翼袖 |
| 视觉密度 | 中 | 高 | 低 | 极低 | 中 |
| 主色 | 烟紫灰 | 褪色青绿 | 深橄榄 | 骨白/钢蓝 | 雾蓝/玉灰 |
| 图形语言 | 半透明植物 | 原创漫画分镜 | 暗提花 | 接缝/色块 | 水纹折射 |
| 品牌位置 | 左胸 + 领标 | 图形边 + 领标 | 同色左胸 + 领标 | 同色左胸 + 领标 | 下摆 + 领标 |
| V2 纹样 | 无 | 无 | 无 | 无 | 无 |

结论：五款在廓形、密度、色彩与图形上均非换色复制；与 Round 2 的结构科技款合并后，V2/机械语言应控制在短袖候选矩阵约 20–25%，其余由本轮五条支线提供情绪和场景跨度。

## 本轮审核问题

1. 每条支线是保留、局部修订，还是淘汰？
2. `CURVE CROP` 的女性友好程度是否合适，是否需要更收腰或更中性？
3. `INK SEQUENCE` 的图形密度是否保留，还是缩减约 20% 留白？
4. `AFTER HOURS` 是否继续作为成熟针织支线，并扩展暗酒红配色？
5. `QUIET UNIT` 是否作为品牌常青基础款？
6. `STILL CURRENT` 的水纹是否需要更抽象或更明显？

审核通过的款式才会进入下一阶段：正、侧、背一致性重建，图形局部放大，材料/色卡定义，再形成可用于技术包开发的统一平面图。
