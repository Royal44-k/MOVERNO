### 尺寸测试

目录：`assets/logo-direction-01/size-tests/`

- 门徽：16 / 24 / 32 / 94px。
- 英文主字标：16 / 24 / 32 / 94px 高。
- 中英双语组合：32 / 64 / 94 / 140px 高。

判定：

- 门徽 16px 仍可识别为抽象 `M`，但中央光缝不稳定；绝对最小 24px，推荐 32px。
- 英文主字标绝对最小 24px 高，推荐 32px 高；16px 时衬线及 `V/E` 切口损失明显。
- 中英双语组合绝对最小 64px 高，推荐 94px 高；32px 时中文副标不可稳定识读。
- 印刷端：门徽与英文主字标最低 8mm 高；双语组合最低 14mm 高；纵向组合最低 25mm 高。
