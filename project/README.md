# 夜行护层 / Night Layer Brand Build

这是“亚裔青年潮流品牌 0→1”项目的执行工作区。当前已锁定视觉方向 1.1：以“静默幕隙”为主，少量融入结构科技感与环境质感。英文主标现为 `MOVERNO`，中文副标为 `墨维诺`；名称已通过内部公开初筛，可进入非公开 Logo 概念探索，但不等于商标核准。

## 已批准基线

- 市场：中国大陆首发，后续扩展亚洲市场；18–30 岁。
- 定位：中端独立设计师品牌；中性视觉；裤装采用 `STRAIGHT` / `CURVE` 双纸样。
- 情绪承诺：暗色第二层皮肤。
- 传播语：暗中移动，保持柔软 / MOVE DARK. STAY SOFT.
- 首发：SS27；短袖阶段已由单一 V2 铺装扩展为“结构科技 + 多条风格支线”的候选矩阵。裤装二级标志已回选 Round 1-B `MV RELAY`；Round 2 的 D/E/F 全部废止。B 的矢量与应用测试、五款纯黑裤装正侧背轮廓已经完成，当前等待轮廓统一审核。鞋履已进入独立确认流程：日韩/国际研究门完成，Logo、纹样、暗色材质与工艺识别板已提交审核，尚未生成完整鞋款。
- 预算基线：约 ¥380,000；Drop 模式为小批现货 + 14 天预售补单。

## 阶段门

1. 研究与命名初筛。
2. 恰好三套独立视觉方向（已完成，用户选择方向 1）。
3. 按命名 → Logo → 标志图案 → 短袖 → 裤装 → 鞋履的顺序逐项确认。
4. 单品确认后，才扩展品牌手册、模特/宣传/社媒与网站。
