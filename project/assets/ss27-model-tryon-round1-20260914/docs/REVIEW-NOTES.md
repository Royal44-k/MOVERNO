# MOVERNO 数字模特上身图 · 审核说明

范围：仅制作 2026-09-14 用户附选的 12 款短袖；每款黑人男、亚裔男、亚裔女各 1 张，共 36 张。每组三张分配正面、侧前方与背面，三类模特轮换展示角度；不是每位模特各三视图。

人物均为生成的成年虚拟模特，不是实拍或真实代言人。身高、尺码、试穿舒适度和实物版型数据未测量，不应从图片推断。

## 制作约束

- 将用户本次选定的每张款式图直接作为服装身份参考，不用新的 V2 铺装替换已选设计。
- 保留本次选定的烟骨／酒红款、深青款以及微 V 领款；历史“全部黑色”要求不用于擅自改色这些已选原图。
- 裤鞋只借鉴用户两张搭配图的垂坠、堆叠和黑白比例；图中裤鞋为生成搭配，不声称是真实 Rick Owens 商品，也不代表合作。
- StyTrix 仅采用参考约束、多视角和逐项修订方法；实际图片由内置 ImageGen 生成，未调用 StyTrix 付费生成。
- 领标按原款设定存在于后领内侧，正常穿着时被颈部遮挡；本批不把领标移至外领，也不声称可从上身图验证不可见领标。

## 质量与使用边界

交付为高保真数字上身／宣传候选图，而非实物摄影、生产封样或已核准发布的商品实拍。生成模型可能在细线拓扑、文字笔画、微小金属形状和褶皱处产生差异，不能保证逐像素一致。最终上架前需按实物样衣核对图案、颜色、衣长、领口与标签，并在实际展示尺寸检查 Logo、手部、鞋面和画面裁切。实物差异不能靠图像暗示来补足。

不从外观推断面料成分、检测表现、功能、可持续性或真实模特授权；发布前另核对素材权利与平台的 AI 内容标识要求。当前未公开发布或部署。
