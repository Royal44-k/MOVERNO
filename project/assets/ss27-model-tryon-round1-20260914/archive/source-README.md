本次 12 款 × 黑人男、亚裔男、亚裔女各一张，共 **36 张最终数字上身候选图**。正面、侧前方与背面在每组内轮换，不是每位模特各三视图。

- 格式：PNG，实际尺寸 1024 × 1536；未做插值冒充高分辨率。
- 制作：内置 ImageGen；StyTrix 仅采用原款约束、搭配、多角度检查方法，未使用其付费生成。
- 审核页：采用 Frontend Design 的原图对照展册布局，窄屏顺序显示、无滤镜遮盖图案；它是本地审核工具，不是品牌官网。
- 模特为生成的成年虚拟人物；本批不是实拍、不证明真实尺码适配。
- 搭配参考用户给出的裤鞋图片；不声称为真实 Rick Owens 商品、联名或代言。

## 审核文件

- `review.html`：按附件顺序 01–12 展示原款与三张模特图，点击图片打开原图。
- `delivery-manifest.json`：36 张最终文件、对应款式／模特／视角、尺寸及逐款检查记录。
- `prompt-set-final.json`：每张图实际使用的提示词与补修提示词。
- `REVIEW-NOTES.md`：原款约束、使用边界与局部修订。
- `references/`：本次设计原图及裤鞋搭配参考副本。

## 使用前

先核对图案位置、Logo、衣长与领口，再对照实物样衣验证面料颜色和印花细节。生成图不能作为印花母版、工厂封样、面料功能证明或真实模特授权文件。领标在后领内侧，正常上身时并不一定可见。图片已做逐图外观检查，但细线拓扑、洗旧颗粒和微小金属边缘不保证逐像素一致；本批交付没有将素材标为“已可直接上架”。
