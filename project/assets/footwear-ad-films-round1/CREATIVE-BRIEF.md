## A01《错位街角》

视觉机制：米灰织面与黑色城市玻璃的温差；地面建筑投影与鞋上链纹以构图呼应，图案本身不变形、不发光。年轻亚裔成年女性模特，短黑夹克、石墨裙裤、米白袜，鞋口完整露出。城市夜色有微暖橱窗光，鞋始终清晰，不以通片压黑掩盖细节。

| 时间 | 镜头与动作 |
|---|---|
| 0–5 秒 | 低机位沿干燥石材街沿跟拍，一步自然落地；先看清米灰鞋面和白胶头。 |
| 5–10 秒 | 中全景：模特从深色玻璃橱窗前走过，夹克衣摆随步伐摆动，保留完整鞋与地面接触。 |
| 10–15 秒 | 微距横移：织物纱线、旧金线与深色双片链纹；拉焦从缝线转到鞋眼，保持真实材质颗粒。 |
| 15–20 秒 | 匹配转场到脚踝三分之四视角；模特停步、脚掌轻转，外侧 MOVERNO 字样正好进入清晰焦平面。 |
| 20–25 秒 | 暗色穿搭全景与低机位侧步镜头呼应；建筑影子掠过地面，鞋面图案保持不动。 |
| 25–30 秒 | 独立鞋款收束镜头，窄幅柔光扫过米灰织面，最后保留至少 2 秒 MOVERNO 标准字标。拟文案：路径，由我编排。 |

声音：脚步、织物轻擦、稀疏电子颗粒与低频节拍。不用参考广告音乐，不加人声推销。

## A02《一道开场》

视觉机制：斜拉链与一道斜切入画面的灯光保持同方向；拉链齿的微光转换成走廊灯的开场节奏，不把鞋本体变成抽象雕塑。年轻亚裔成年中性模特，黑色长外套、短层次内搭、深灰及膝裙裤，露出完整高帮。

| 时间 | 镜头与动作 |
|---|---|
| 0–5 秒 | 极近景扫过银色拉链齿与拉片，斜光从左上进入；不先用五秒空黑场。 |
| 5–10 秒 | 坐姿穿搭镜头：手整理直立鞋舌与鞋带，轻压脚跟入位；不表现不合物理的穿鞋或悬浮鞋带。 |
| 10–15 秒 | 自然起身迈步；机位在鞋侧跟拍，外侧斜链纹、银拉链及适中底厚同框可见。 |
| 15–20 秒 | 全身穿搭进入窄暗廊，衣摆有重量，模特停下再转向灯光；动作不做夸张机械扭转。 |
| 20–25 秒 | 链纹窄嵌条、帆布表面和底墙徽记三处短微距接续，光线的斜向移动是唯一局部动效主线。 |
| 25–30 秒 | 三分之四鞋款 hero 镜头接 MOVERNO 收尾。拟文案：由这一道，切入。 |

声音：金属拉片轻碰、步音、短促工业打击乐。保持清晰动态留白，不全程高强度轰鸣。

## A03《重力留白》

视觉机制：真实地面承重与大体积奶油底，配极简建筑空间和低机位；表现鞋的尺度，不做腾空、踩碎地面或未经测试的性能暗示。年轻亚裔成年中性模特，修长黑外套、短裤或短裙式内搭、烟灰高袜；避免长裤完全遮鞋。

| 时间 | 镜头与动作 |
|---|---|
| 0–5 秒 | 地面近景：巨厚底从画外自然进入并落地，重心明确，橡胶底不夸张压缩。 |
| 5–10 秒 | 底墙和大胶头的微距弧形移镜，斜侧柔光显露连续弧面与微小纹理。 |
| 10–15 秒 | 模特沿宽阔混凝土台面走三步，低角度中全景，鞋底比例始终与原图一致。 |
| 15–20 秒 | 模特停步、半转身，布料惯性轻摆；摄影机轻绕行，鞋带自然下垂，没有自主漂浮。 |
| 20–25 秒 | 直立鞋舌徽记与侧墙浅压纹各一处细节，背景投影缓缓移动，鞋本身静定。 |
| 25–30 秒 | 宽幅建筑留白中的完整穿搭接鞋款 hero，MOVERNO 收尾。拟文案：步伐，自成尺度。 |

声音：克制的低鼓、脚步和空间短回声；与 A01 的城市颗粒、A02 的金属切拍区别开。

## 制作路径与当前阻碍

本次已读取 Runway 连接状态：认证正常，但固定工作区为 Free，`availableVideoModels` 为空，没有第二个可切换工作区。账户有点数不等于拥有视频生成权限。已展示计划与点数卡，没有提交任何扣费生成，没有购买、升级或充值。

自然人体运动需要实际视频生成或已有拍摄素材。HyperFrames 可承担后续剪辑、局部图形与标准字标收尾，但不能把静态模特图的平移／缩放当成自然行走视频。HeyGen 当前默认数字分身／口播流程不是这三支鞋履动作广告的合适替代。

用户现已明确不使用付费方案，因此不再以升级 Runway 或开通付费视频权限为制作前提。

2026-09-11 实际核验 [Pika 官方定价页](https://pika.art/pricing)：Basic 为 $0，列有每月 80 点、Pika 2.5 的 480p 权限，以及 5 秒图生视频每次 12 点。进一步检查实际页面权益图标：无水印下载、商用两项均使用叉号 `check-circle-x`，不是免费权益；额度和模型权限使用勾号 `check-circle`。因此不能把该免费档作为本项目商用广告的生产渠道，也不能只依据提取出的文字认定免费可商用。未登录、未上传三款设计、未提交生成。

目前尚未确认一条同时满足零付费、允许商用、可生成自然人体动作的可用渠道。不能用静态图缩放代替要求中的试穿动作，也不能将低清素材封装到 1080p 后称为原生高清。后续需有用户授权且可商用的免费动作生成渠道，或有使用权的对应款式试穿视频，再继续合成三支 30 秒成片。

生产条件具备后，生成前后分别检查鞋型锁定、左右脚连接、腿脚数量、行走重心、鞋带穿孔与字标漂移。成片不主动添加“AI生成”片内字样；不擅自移除服务商强制水印或其他来源标识。
