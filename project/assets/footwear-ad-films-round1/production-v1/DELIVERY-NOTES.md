# MOVERNO 三款 30 秒广告 — 首轮审片

## 成片位置
交付文件在 `renders/final/`。A01《错位街角》、A02《一道开场》、A03《重力留白》。该目录才是裁齐音视频时长的交付版本；上级目录 v1/v2 是保留的中间渲染。

## 规格与边界
- 每支 1080×1920、30 fps、900 帧、H.264 + AAC；最终容器、视频流及音频流均验证为 30.000 秒。
- 试穿源片各 480×832、16 fps、57 帧（3.5625 秒），从用户授权的指定 Hugging Face 免费演示取得。成片是放大输出，不是原生 1080p 的试穿素材。
- 每款使用一段独立人物动作，分别以全景和更近构图呼应使用，约占成片 6.5 秒；不是两段不同的实拍动作。其余为原图细节特写、暗色产品镜头、品牌片尾和转场。
- 人物是合成的逼真模特视觉，不是实际拍摄或真实消费者体验；片内按要求没有添加“AI生成”字样。无口述证言、无虚构产品性能。
- 细节镜头是摄影图像的编辑动效，不声称来自实物 3D 扫描。动态小字标可能有轻微漂移，源分辨率也限制放大细节，需审片后再决定正式投放。

## 两个插件实际分工
HyperFrames：标准双片徽记、原始 MOVERNO 字标和片尾标记的 GSAP 动画，已本地渲染为 `remotion/public/assets/brand-signature.mp4`，并实际用于三支成片。

Remotion：三款独立时间线、人物视频、产品特写、暗色产品主镜头、短溶解转场、独立原创合成配乐以及最终本地渲染。使用 frame-driven 动画和独立场景组件，保留可编辑源项目。

## 费用与素材处理
未购买套餐、未充值、未升级、未启用需要付款的试用。用户确认符合 Remotion 个人／不超过三人团队的免费使用条件。Wan 处理采用匿名客户端，只访问用户指定并同意上传的 `zerogpu-aoti/wan2-2-fp8da-aoti-faster` 演示，没有账户令牌、付费回退、空间复制或额度规避。只上传制作中的模特关键帧，没有向其他视频服务上传。

HyperFrames `lint` 和完整 `check` 均通过：运行无错误、9 个布局采样无问题、动效无错误、4/4 文本对比度通过。旧版 skill 的独立 animation-map 脚本因缺少私有 `@hyperframes/producer` 包无法运行；采用当前 CLI 内置 Motion 检查和实际片尾渲染抽验补充，未伪称独立脚本通过。
