# MOVERNO SS27 Footwear Concept Round 3 — Prompt & Design Contract

Date: 2026-09-03  
Status: awaiting user selection; none of these concepts is approved for technical-pack use.

## Shared generation contract

- Exactly one left shoe; exterior three-quarter view; toe points right; whole shoe remains in frame.
- High-fidelity 1536×1024 product render on the same warm neutral-gray seamless studio background.
- Stay visibly within the assigned reference category and proportions. Do not drift into boots, sock shoes, ballet hybrids, sandals, sculpture, or costume armor.
- Remove every third-party logo, signature side mark, exact panel map, heel plaque, foxing stripe, and outsole trade dress.
- Use the approved MOVERNO gate emblem without generated letters. Final wordmark placement is reserved for vector compositing.
- Use the approved Motion Contour / veil-hourglass pattern as structure: quarter panel, abrasion layer, cage, molded relief, translucent internal field, or zipper channel—not as a random pasted graphic.
- Palette: Obsidian black, graphite, bone ash, or sand. Aged-brass line stays below 1%; dried-blood red is one tiny stress bartack. No bright colors.
- Young Asian dark-luxury: Tokyo/Seoul credible, refined, wearable, and manufacturable.

## Direction deltas

1. **SAND RELAY / 沙幕复古跑** — Sand technical-runner reference; flowing retro-runner layers; one enlarged pattern cell as suede quarter overlay.
2. **BLACK WAVE / 黑曜波层跑** — Same category in near-black; sculpted wave layering; opposing hot-melt pattern ribs around a narrow gate slit.
3. **VEIL CROSS / 幕隙绑带跑** — Cross-cage reference; broad low technical shoe; pattern becomes flexible crossing rails anchored at real load points.
4. **SHROUD RUNNER / 低覆护罩跑** — Retro-runner plus cage references; a single restrained removable lateral shroud is the only extra variable.
5. **RELAY SKATE / 接隙板鞋** — Low skate references; pattern becomes a two-layer abrasion structure; conventional lace/throat and credible cupsole.
6. **VEIL LOW / 幕隙低帮** — Thick black-and-bone fashion-low reference; enlarged opposing leather quarters create the side gate.
7. **MONO STACK / 单色厚底** — Monochrome platform court references; shallow pattern relief is molded into the bone sidewall.
8. **SQUARE COURT / 方头球鞋** — Court-low references; only silhouette trend variable is a soft anatomical square toe.
9. **VEIL CANVAS HI / 幕隙帆布高帮** — Classic canvas high-top reference; vertical pattern cell is an ankle reinforcement, with no circular patch.
10. **PADDED VEIL HI / 软甲皮质高帮** — Padded black/bone high-top reference; pattern becomes softly articulated padded leather quarters.
11. **GHOST CONTOUR HI / 幽幕半透明高帮** — Translucent high-top reference; approved pattern appears beneath the outer layer at about 15% contrast.
12. **REGISTER ZIP HI / 暗档拉链高帮** — High-top references; one concealed practical zipper sits inside the vertical gate slit while laces remain functional.

## Selection gate

The user selects one display-order number from 1–12. Only that concept may then receive single-variable revision, multi-angle consistency work, last/sole matching, and a Rev A factory-enquiry tech pack.
