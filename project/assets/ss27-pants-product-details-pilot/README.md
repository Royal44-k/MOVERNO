# MOVERNO SS27 裤装产品详情试制

本目录包含三款裤装详情视觉试制：PT19 FLUID RELAY、PT25 MINERAL PUDDLE（中性矿物灰）和 PT28 APERTURE CARGO。

## 查看

- `index.html`：本地审核入口。
- `overview.png`：三款首屏索引。
- `posters/`：三张 1080 × 5080 px 产品详情长图。
- `editable/`：三份自包含 SVG，品牌标识与文字可编辑。
- `slices/`：每款六张独立模块切片，共 18 张。
- `heroes/`：三张无文字商品主视觉。
- `previews/`：360 px 宽审核缩略图。
- `manifest.json`：输入、输出、提示词及 SHA-256 记录。
- `qa-report.json`：尺寸、嵌入资产、文案和切片自动检查结果。
- `qa-branding-contact.png`：三款主视觉与品牌触点总表。
- `qa-mobile/`：三张 375 px 宽移动端可读性预览。

## 六模块

1. 主视觉 / HERO
2. 廓形 / SILHOUETTE
3. 单链解剖 / RELAY ANATOMY
4. 品牌触点 / BRAND TOUCHPOINTS
5. 材质与动态 / MATERIAL IN MOTION
6. 品牌收束 / BRAND CLOSE

## 品牌资产分工

- Veil Gate：主品牌徽记与品牌收束。
- MV RELAY：裤装二级标，用于后腰牌、纽扣、抽绳端头和拉链头。
- V2：裤侧单链视觉母版；鎏金只在边缘，暗色内部保持不变。
- MOVERNO 字标、中文及英文文案均在 SVG 中确定性排版，不采用图像模型生成文字。

## 使用边界

本轮是概念宣传视觉，不是实物摄影、量产商品资料或工厂技术图。版型、材质、色彩、图案、标识尺寸和五金须以实体封样为准；未添加未经验证的性能、人体工学或可持续声明。
