## 方法与证据边界

采用 StyTrix 的参考拆解、版型／材质／品牌落位分解与复核流程；没有调用其付费生成，也没有使用 sketch。图像由内置 ImageGen 生成。下列六张官方商品图已由主代理实际打开观察，并作为独立参考文件保存。参考图里的其他品牌仅用于识别来源，不能作为 MOVERNO 商品宣传资产使用。

“已观察图片”描述可见形态；“设计推导”是本轮构思，不是来源品牌的产品功能。材质均为提案，图片不能证明真实成分、舒适、防滑、防水或耐久表现。

本轮是公开官方商品与企划的视觉研究，不能据此宣称全面研究小红书、Instagram 或中日韩所有社媒，也不把单个在售商品等同于销量趋势。日本／韩国资料的独立文字核验见 `research/JAPAN-KOREA.md`；该研究助手未看图片，主代理随后自行观察选用图像。
