## 使用与边界

StyTrix 只采用参考拆解／版型／材质／品牌落位／复核流程；没有付费生成，没有 sketch。实际图像由内置 ImageGen 制作。

本批仍为概念审款，不是多视图产品详情页、实拍或 Tech Pack。鞋舌、后跟、鞋底板等不可见部分未被自动认定为已完成。主图中的徽记／字标／纹样是图像模拟，不能代替标准矢量；量产前需回套品牌资产并验证结构与材料。

参考图片与品牌名用于私人设计研究和内部比较；不要把他牌官图作为 MOVERNO 商品宣传图、合作背书或量产授权。对舒适、保暖、防水、防滑、增高、寿命均不作未经测试的承诺。
