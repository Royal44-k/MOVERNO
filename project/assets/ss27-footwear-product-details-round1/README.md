# MOVERNO SS27 · 产品详情图审核包

本轮沿用指定的 10 款设计。第 3、5 款使用最新侧身纹样改版，其余使用用户指定的 Round 6 概念图。没有覆盖此前保留的款式或原始概念图。

## 查看方式

- 打开 `index.html`，按原编号浏览全部款式。
- `posters/`：10 张独立产品详情 PNG，1080 × 5080 px。
- `views/`：每款外侧、内侧、正面、后跟、俯视、底面六面概念展示。
- `editable/`：自包含 SVG，中文、标题、注释和版式可编辑；鞋履与纹样为嵌入的栅格图，不是鞋版 CAD。
- `previews/`：适合快速审核的缩略图。
- `overview.png`：10 款主视觉索引。

## 详情图结构

每款包含：独立主标题 → 已选概念图主视觉 → 三个可见设计卖点 → 六面展示 → 品牌理念 → 两张原款局部特写 → 后跟／鞋舌及底面标识特写 → 配色方向 → 穿搭建议 → 收藏引导。

品牌理念：让黑夜不必黯然，让差异不必喧哗。

品牌信念：Different But Excellent.

新标识按位置分工：鞋侧承担第一识别；鞋舌或后跟承担小型落款；多数款式的底面通过同色门徽回应。流银款的底面结构较密，新增落款集中在后跟底，底面不再叠加标识。保留黑、骨灰、银白和烟胶色关系，不增加大面积高饱和彩色。

## 使用边界

这是用于设计及宣传方向审核的概念详情图，不是实物摄影或已量产商品资料。新增的内侧、后跟、俯视及底面，是基于原概念的视角和品牌细节延展；结构、鞋底纹路、标识尺寸、工艺和颜色须经实物样鞋确认。

文案仅围绕可见的轮廓、拼接、纹理、标识与色彩展开。未添加未经测试的舒适、轻量、防滑或耐用等性能承诺，没有价格、库存、虚构评价或促销倒计时。尚未公开发布。

## 过程记录

`products.json` 保存每款文案、主视觉源图和原图裁切位置；`branding.json` 保存新增品牌细节说明；`prompts.json` 保存初始提示词；最终实际生成及修订提示词、生成源路径和质量核对记录见 `manifest.json`。

图像使用内置 ImageGen 生成。StyTrix 仅用于参考锁定、品牌约束和逐项核对的设计流程，未使用其付费生成。中文和正式品牌字标单独排版，避免把生成文字作为正式文案。
