# MOVERNO SS27 — Reference-faithful footwear concepts, Round 4

This folder contains eleven independent 1536×1024 concept renders generated on 2026-09-03. The six previously shortlisted shoes in `../ss27-footwear-shortlist-round3/` were not changed.

The work used StyTrix only as a no-cost process framework: orient, preserve the reference, change one brand variable, review, then select. All raster generation used the built-in ImageGen tool. No StyTrix credits or paid generation calls were used.

Each image is grounded by one user-provided shoe reference plus the approved MOVERNO Motion Contour and gate emblem. Third-party names, typography, monograms and logos are excluded. These images are concept-direction assets and must not be treated as factory-ready technical drawings.

Selection is by the order in which the eleven images appeared in the conversation. After selection, only the chosen design(s) move to consistency correction, multi-angle views, outsole/last matching and technical-pack development.
