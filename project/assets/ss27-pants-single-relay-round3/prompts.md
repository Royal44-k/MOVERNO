# MOVERNO SS27 Pants — Single Relay Round 3 Prompt Set

## Shared generation contract

- Use case: `product-mockup`.
- One landscape concept board per style: the same garment in front, strict side and back views, plus three close-up insets.
- Neutral warm-gray seamless studio, neutral white light, no text, model, top or third-party branding.
- Reference master: `05-relay-veil-edge-gilded-v2.png`.
- Preserve V2 hourglass/veil topology, graphite interior, narrow negative space and dried-blood nodes.
- Use one dominant chain only. Apply `anchor — breathing gap — echo`; prohibit parallel full chains, three stripes, equal repeated borders, rectangular motif patches, tribal, flame, heart, cross, crown, spike, weapon and armor forms.
- Gold, when used, stays on the edge and never enters the dark interior.

## No-blue main-series negative color prompt

`Absolutely no blue, navy, indigo, teal, cyan, violet-blue or blue-gray. No colored studio rim light and no brown cast.`

## Blue A/B edit prompts

Blue variants were edited from the corresponding no-blue image with a strict color-only instruction:

- PT22: lead-iron black → deep indigo-black monochrome washed denim.
- PT23: pomegranate-black → midnight navy technical woven.
- PT25: neutral mineral/chalk gray → cold mineral gray with pale dusty-blue dirty wash.
- PT27: oxblood-black → restrained blue-black stretch twill.
- PT30: tungsten gray → muted oxidized blue-gray wool-nylon.

Every edit instructed the model to preserve silhouette, seams, views, motif topology, scale, placement, hardware, crop, background and lighting and to change only textile color.
