- 旧15的巨大分块跑鞋底、外延后跟荚、笼架、缠绕绑带、宽大侧牌、厚垫高帮都不作新款母版。
- 固定品牌标识可重复；应用工艺不独立作为每款的新发明。
- 品牌图形准确性单独复核；不把三叶、蝴蝶、X 当作双片徽记。
- 当前系列只说明可见设计，不使用未经测试的舒适、保暖、防滑、增高及材料成分承诺。
