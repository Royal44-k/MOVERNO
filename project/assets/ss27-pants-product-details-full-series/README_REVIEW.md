# MOVERNO SS27 裤装产品详情页审阅包

## 审阅入口

- `overview.png`：15 款详情页首屏与版式节奏总览。
- `model-fit-overview.png`：15 款男女试穿与自然动作总览。
- `index.html`：本地浏览索引，可进入每款完整长页。
- `posters/`：15 张 1080×6500 产品详情长页。
- `previews/`：15 张快速预览图。
- `mobile/`：15 张 375px 移动端检查图。

## 系列边界

- 主系列 12 款不使用蓝色；`PT22-B`、`PT25-B`、`PT27-B` 仅置于 `COLOR_LAB`，用于用户要求的蓝色系对照。
- 每款详情页使用 6 张独立图片，不在同一页面重复图片或裁图。
- 男女模特统一穿着锁定的 MOVERNO Oversize 上衣与高帮鞋；部分款式已更换不同面孔与自然行走、转身动作。
- 品牌标识只出现于裤装触点和穿搭产品中，不设置孤立 Logo 展示卡。
- V2 纹样母版哈希：`6974B12D59755D954DA3B748736218DB78C7B3542D954BEA3EC1E1F040689D76`。
