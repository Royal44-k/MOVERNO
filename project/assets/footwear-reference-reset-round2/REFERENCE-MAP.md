## 本轮决策

主图必须能与参考直接核对鞋型：低口/后空、筒高、圆头体积、厚底和鞋带量感是硬约束。品牌纹样、字标与局部拼接是变化层，不再为了“原创”把饱满鞋型改瘦、把厚底统一压薄，或把绒拖改成保健短靴。

StyTrix仅使用轮廓/材质/工艺拆解及复核流程；不调用收费服务、不用sketch。内置ImageGen采用用户鞋图作为直接参考输入。每款选定后保存独立主图和附原参考缩略图的4:5审款板。
