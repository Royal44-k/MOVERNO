本轮根据用户最新上传的 11 张鞋型图执行，合并为 6 组。N01—N06 已被整批否决，不作为本轮正向参考；旧图保留，不覆盖、不删除。本轮六款全部等待用户审核。

## 先看这些文件

- `index.html`：本地审款入口，打开即可查看六款总览与原图对照板。
- `overview-R01-R06.png`：六款横向比较总览，3300 × 2400。
- `boards/R01-board.png` 至 `R06-board.png`：六张 4:5 审款板，1600 × 2000；每款都附相应的用户原参考缩略图。
- `masters/`：独立主图，1536 × 1024；最终版本以 `selected-assets.json` 为准。
- `editable/`：七张自包含 SVG 排版，图片以内嵌形式保留。它们是可编辑图文排版，不是鞋型 CAD。
- `REFERENCE-MAP.md`：逐图观察、参考映射与已实际执行的联网研究；区分看过图片与仅核验正文。
- `QA.md`：人工复核与留待打样的问题。

## 制作及文件边界

StyTrix 仅采用参考、版型、材质与工艺拆解和复核流程；不调用付费生成、不使用 sketch。鞋履图通过内置 ImageGen 生成，版面以 SVG 排版后输出 PNG，没有用代码描画或拼改鞋身。

`prompts.json` 保存六款完整初始提示词及输入路径；`revision-prompts.json` 保存 R05 局部修改提示词；`selected-assets.json` 保存选用图片及生成原文件路径。生成原文件留在原处。

主图是设计概念，不是实物摄影。鞋上品牌标识为视觉模拟，量产须回套标准矢量；本轮没有假定完成背面、底板等未显示部位的设计，也没有把单张主图冒充多角度实拍。材质配色为提案，结构、贴合、耐久及性能待打样验证。

用户原参考中的 UGG、Rick Owens 类高帮、OCAI、Burberry 等标识仅用于识别参考来源，不属于 MOVERNO 新款。新鞋图不使用他牌字标或 Burberry 格纹。本次是参考导向概念，不宣称全部鞋型具有独占原创性。
